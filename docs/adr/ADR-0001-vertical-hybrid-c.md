# ADR-0001: Vertical strategy \u2014 hybrid C

Date: 2026-09-25  
Status: Accepted (owner will audit before treating site as final)

## Context
Need sales surface without inventing clients or metrics. Single-vertical lock vs multi-approach tension.

## Decision
**Hybrid C**
- Public lead niche: specialist clinic & professional services \u2014 Lagos
- Reference architectures (explicitly labelled): hospitality, gig/job platform, internal ops
- Evidence classes on site: builder-operated \u00b7 reference \u00b7 engagement in progress \u00b7 client-consented

## Consequences
- Vertical OS and Business proof aligned to labels
- No metrics until instrumented engagement
- Gig Pilot\u2013shaped work is reference/client scope, not LOG_ON identity
- Next: one evidence artefact + first lead-niche workflow

## Alternatives rejected
- A pure multi-approach with no public lead (weaker focus)
- B single vertical only (less sales surface this week)
